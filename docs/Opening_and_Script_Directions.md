# PART 1 — 三个开场方案

## 开场 A · 「偷听 + 接通请求」（黑屏方案加强版）

上次说的黑屏偷听，加三个「更特别」的东西：配对界面本身当演员、玩家亲手接通、马克杯瞬间。

**逐拍：**
1. 纯黑。app 风格的字：`配对中……` → `已匹配` → 一张模糊的资料卡片滑入：`Yua · 音频已连接 · 视频连接中……`
2. 还是黑的。**先听到她**：键盘声，断断续续。退格键连按一串。小声嘟囔：
   「……不对。这句昨天就该删了。」（键盘声停）「为什么写出来就……唉。」
3. 屏幕中央浮出一个按钮——**`对方音频已开启 · 点击接通视频`。玩家自己点。**
   （第一次交互不是「继续」，是你亲手接起这通电话。视频里这一下点击就是钩子。）
4. 画面亮起：房间、傍晚光，她正端着马克杯喝水——**定住**。慢动作把杯子放下。
   「……从、从什么时候开始算连上的？」
5. 镜头外一阵手忙脚乱的纸张声，她把什么东西推出画面。「你刚才……什么都没听到吧。」
   「……好。那就当没听到。」（清嗓子）「你好。我叫 Yua。」
6. 之后进正常流程（取名、试话筒、计时器邀请）。BGM 到她说
   「我这边放点东西，你介意吗？」才淡入——音乐是她给的，不是 UI 给的。

**成本：** 音效若干（键盘/退格/纸张/接通音）+ 一张「端杯子定格」差分立绘。无 CG。
**钩子原理：** 前 15 秒偷听到秘密 → Ep5 变成回收而不是冷启动；「点击接通」给视频观众一个动作记忆点。

## 开场 B · 「她那边的桌子」（AI 视频方案 — 你能做的额外资产）

用你能生成的 AI 视频做一段 **10–15 秒她那侧的第一人称生活流**，代替 CG：

**镜头脚本（无人脸，规避 AI 视频的脸部漂移问题）：**
雨点敲窗 → 桌面：一摞没拆封的笔记本、印着海豚（小七）的马克杯冒热气 → 一只手把
写了一半的纸页翻扣过去 → 远处轮渡汽笛声 → 手移向屏幕，光标悬在「接受配对」上——点下。
**硬切**：游戏 UI 亮起，你就是这通电话的另一头。她的第一句：「……接通了？诶，比我想的快。」

**成本：** 一段 AI 视频（手 + 桌面 + 雨窗，Seedance 这类模型的舒适区）+ 环境音。
**钩子原理：** 3 秒内传达「对面是个真实的人，她刚刚也犹豫了一下才接」。这段视频同时就是
小红书封面素材——一条素材两用。
**加分项：** 翻扣纸页 = 秘密第一次出现，和 A 的偷听同一个作用，但纯视觉。

## 开场 C · 「先专注，后见面」（最大胆，概念最纯）

游戏打开时**计时器已经在走**，她在专注，根本没发现你连上了。没有问候，没有教程。
15 秒安静：她写字、停顿、揉手腕，雨声，计时器走。——铃响。她伸懒腰，一抬头：
「啊——响了响了。……诶？！你什么时候连上的？这 app 也不提醒我一声！」
「……你就一直坐在那儿看我写东西？」（耳朵红）「算、算了。反正以后也是这样各干各的。」

**成本：** 零新资产（用现有立绘 + 计时 UI 演戏）。
**钩子原理：** 没有任何同类游戏敢用「沉默」开场；它用倒叙教会玩家核心循环（先共处，后说话）。
对「刷到视频的人」尤其猛——前 5 秒的悬置感（怎么没人说话？）就是停留钩。
**风险：** 没有引导，急性子玩家可能困惑。适合做视频开场，游戏内可作为「二周目彩蛋开场」。

# PART 4 — AI 口吻对齐（从今天的真实 API 采样中提炼）

用游戏同款 persona 调了 10 个场景（样本存 scratchpad/yua_voice_samples.txt）。
AI 版 Yua 确实更可爱，可复制的具体手法有五条——上面三版剧本已按这五条写：

| 手法 | AI 实例（今天采样） | 脚本要怎么学 |
|---|---|---|
| **接住具体细节，不接情绪概念** | 玩家说地铁上柯基屁股圆 → 她认真讨论「地铁上的圆屁股画面超出认知范围」 | 分支回应要 riff 玩家选项里的具体词，不要「哈哈是呀」 |
| **问完就给台阶** | 「你那边是周末还是工作日？……当我没问，不用答。」 | 每集至多一个问句，且问句后面永远跟一个「不答也行」的软出口 |
| **世界感从缝里漏** | 「什么都不开，就听外面海的声音」 | 每集至少一个感官细节（汽笛/潮气/瓜子/白板），但只作配菜 |
| **两拍式小幽默** | 「要不先躺一会儿，等会儿再躺。」 | 笑点=正经开头+歪掉的第二拍；不用感叹号制造可爱 |
| **自嘲式撤退** | 「说出来我会害羞，然后又会把它关掉。」 | 害羞时刻用「预告自己会怂」代替省略号硬挡 |

**顺手发现的两个 persona 缺陷（建议我下个 session 修）：**
1. 有一条回复漏了舞台指示「（稍微停顿了一下，没再接下去）」——违反 persona 的
   NO stage directions 规则，需要在 runtime rules 里加一条「绝不输出括号动作」。
2. 玩家表白测试里她回了「……嗯，我也是」——超出「soft ambiguity at most」的边界，
   需要把拒绝示例写进 rules（给一句标准软挡台词）。

**你提议的「让 AI 当写作陪练」——采纳，落地方式：**
做一个 `tools/yua_draft.py`：输入某一集的场景说明，让带完整 persona 的模型生成 5 版
候选台词 → 我按上面五条手法筛选改写 → 进 JSON。人（你）终审口吻，AI 供素材，
脚本和 AI 模式的声音自然就会长在一起。**⬜ 要 / 不要**
