## 2. 我们比 CWYL 强的地方——把它做实

### 2a. 小本子（owner 的想法）— 建议：**做，作为 demo 的核心镜头**
设计已在 `docs/Yua_Notebook_Design.md`。它一次解决三件事：可视的「她有生活」、每次回访自动产出新内容、
写作线的回避可视化（『我的小项目』划掉又重写）。三个待定我建议：
1. 代称 → **「我的小项目」**（已在剧本里统一，直接用）。
2. 日常池 → 用设计稿的四池；**再加一条固定的「别打游戏」**，反复划掉又写上，是最便宜的笑点。
3. 回访提一句的频率 → **每次隔天回来必提一句，同一天不重复**。比 50% 稳，玩家能学会「她真的在过日子」。
成本：`notebook_manager.gd` ≈150 行 + 池 JSON + 任务面板加「她的区域」。一天。
**和今天的 `return_open_days` 是同一根线**——本子做好后，那句「荐书卡三张、小项目零行」就从硬写变成本子里真实划掉的条目。

### 2b. 今日荐书卡 — 建议：做，很便宜
书咖世界的核心道具却从没出现。做法：每个真实日期她「写了一张荐书卡」，HUD 角落一张小卡（书名占位 +
一句她写的推荐语，池 15 句），点开能看。她在问候里顺口提一次（「今天那张写得还行」）。
这是「每天都有人在读她写的字」设定的唯一可视证据，也是后期「有一张被拍到网上」剧情的伏笔位。
成本：半天 + 15 句。

### 2c. 「她也下班」— 建议：做，回应小黑盒最独特的诉求
玩家怕她「全年无休」。规则：现实 23:30 后启动 → 她在，但灯只开台灯、说「我也就再坐一小段」（夜间问候已改）；
连续在线 > 2 小时 → 她起身一次（动画层已有喝水/看窗），加一句「我站一下」。**不做**「她下线不陪你」——那是惩罚。
成本：1 小时（只是条件 + 2 句）。

### 2d. 平台记忆回调 — 建议：做，剧本 session 顺手
Ep3 存了 `player_platform`，之后从没用过。Ep7 或 Ep9 加一句条件回调（B站/小红书/抖音各一句）。
这是「她记得你」在剧本里的第一次兑现。成本：3 句 + 1 个条件分支。

## 3. 不建议做的

- **服装/换装系统**：与「她是人不是娃娃」冲突；小黑盒研究显示核心玩家对此警惕。季节居家服最多 1–2 套，后期。
- **她主动催休息/管理时间**：违反 AGENTS。
- **成就/徽章/在线时长解锁**：CWYL 差评区最热的坑，我们的差异点就是不做。
- **语音**：脚本定稿前不做（每改一句作废一批）。

## 4. 建议顺序（在 demo 前）

1. 小本子（2a）— 一天，demo 视频最佳镜头
2. 工作中自语（1-1）— 半天，「她在那儿」质感
3. 今日荐书卡（2b）— 半天，世界观第一次可视
4. 一天第 N 段 + 她也下班（1-2 / 2c）— 各 1 小时
5. 节日槽（1-3）— 半天，可以 demo 后
6. 周末番外（1-7）— 剧本 session 排期

合计约 3 天 Claude 工作量，owner 决定 2a 的三个问题即可开工。
