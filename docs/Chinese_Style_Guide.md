# 中文风格手册（2026-08-14）— 所有润色/审校的统一标准

这个文件是「合同」：人写、Claude 写、别的模型润色，最后都拿它当验收标准。
`tools/zh_polish.py` 每次运行都会把本文件整个喂给润色模型。改这里 = 改整条流水线的口味。

---

## 一、通用规则（文档、卡片文案、UI 文本都适用）

### 翻译腔黑名单（见一个改一个）
1. **「被」+抽象动作**：「她的文字被使用」→「常客买书就认她写的卡」。真实中文少用被动，
   多用具体的人做具体的事。
2. **「进行/作出/加以」+名词**：「进行创作」→「写」。动词直接上。
3. **「作为 X 的 Y」开头**：「作为店员的她」→「她站在柜台里」。
4. **名词化堆叠**：「她的努力有了着落」这类「抽象名词+虚动词」，改成看得见的画面：
   「荐书卡越写越认真」。
5. **长定语**：「一个叫『杂物』的锁在电脑里的文件夹」→ 拆句：「电脑里有个文件夹，
   名叫『杂物』。」定语超过 10 个字就拆。
6. **破折号滥用**：一段最多一处「——」。两个以上说明句子结构该重排了。
7. **「的」连用**：一句里连着三个「的」就重写。
8. **欧化比喻**：「剧情的火从这点燃」这种直译腔比喻，要么换成中文里真会说的
   （「故事就从这儿开头」），要么删。

### 节奏
- 口语/台词：一拍（一口气读完的单位）不超过 20 字。
- 文档：一句不超过 40 字；连续三句同结构就变化一下。
- 读出声测试：任何一句读着喘不上气或者绕口，就是要改的。

### 标点
- 全角中文标点；省略号统一「……」（六点）；不用「~」卖萌；感叹号一段最多一个。

## 一点五、目标线（2026-08-14 起，所有台词按这个验收）

- 及格线不是「通顺」，是**比《Chill with You》的中文本地化更好**：更可爱、更地道、更有梗，
  同时保持二次元少女感。
- **可爱从哪来**（按关系熟悉度递进）：初识 = 紧张之后自我化解（「刚才那个是打哈欠」）；
  熟了 = 共享小秘密（「这周那张荐书卡我先不擦了」）；更熟 = 轻微的理直气壮
  （「这杯水现在是我的专注道具，不接受质疑」）。不靠语气词堆砌——嘿嘿/呀/啦每段最多一处。
- **有梗但不玩网络梗**：梗要长在情境里（辣条抵账、拉花神似小七），网络流行语一律不用
  （绝绝子/yyds/家人们这类——她不是网红，是有点宅的书店店员）。
- **二次元感的来源**：反应夸张一点点（——诶？！）、吐槽有节奏、偶尔中二上头又自己急刹车。
  不是称呼卖萌（桑/酱/大人已禁）。
- 每句话的终极检验：**一个 21 岁有点宅的女孩子，当下会这么说吗？说出来观众会想截图吗？**

## 二、Yua 台词专用（叠加在通用规则上）

来自 AI 采样提炼的五手法（写和改都要过这五关）：
1. **接具体，不接概念**：回应对方话里的具体词（柯基、辣条、三十六度），不说「哈哈是呀」。
2. **问完给台阶**：每段至多一个问句，问完补一个「不答也行」的软出口。
3. **世界从缝里漏**：每段至多一两个感官细节（汽笛/拉花/瓜子），是配菜不是主菜。
4. **两拍幽默**：正经开头 + 歪掉的第二拍。不靠感叹号和语气词硬凑可爱。
5. **自嘲式撤退**：害羞时预告自己会怂（「说出来我会害羞，然后又把它关掉」），
   不用省略号硬挡。

硬规矩（persona 同步）：「……」每段至多一次，多数段落一次都不用；不开头就「……」；
不喊口号（加油/你真棒/我们一起努力）；不说「喜欢/爱/想你」；不输出括号动作。

## 三、文档/给 owner 看的文案专用
- 读者是非技术者：每个专有名词/人名/梗，**首次出现必须当场解释**（小七教训）。
- 比喻要落地：写完问一句「中文里真有人这么说吗？」，没有就删。
- 短段落，一段一个意思；能用具体画面就不用抽象概括。

## 四、流程（谁写都一样）
1. 起稿（内容和结构对就行，先不追求漂亮）。
2. `zh_polish.py` 跑一遍 → native 模型按本手册改写 + 列出改动理由。
3. Claude 复核：只查硬规矩有没有被改坏（persona 红线、事实、术语）。
4. Owner 只看争议处（工具会标出改动大的句子），不用逐字过。
