# 游戏其他部分 · 草案 v1（2026-09-23）

> 配合《主线大纲 v3 · 章回版》。这里是主线之外玩家每天真正听到的东西：**启动场景（匹配问卷）**、**开场问候与回流**、
> **闲时 / 专注中 / 自语 / 收工 / 离开**，以及 **Yua 的小本子 v2**。台词全部是草稿（标 🅳），先定机制和方向，语言后打磨。
> 铁律照旧：她是搭子不是监工；不查岗、不约下次、不催；每处 AI 都有脚本兜底；省略号一段最多一处。

## A · 启动场景 · 「匹配」问卷

### 目的
让相遇有理由（「系统把我们配在一起是因为……」），顺手拿到三样以后一直用得上的信息；**只问游戏真会用的**，不问年龄性别。

### 流程（首次启动，黑屏，app 的声音，不是 Yua）
```
[1] Project Chill · 找个搭子一起专注              （淡入，2 秒）
[2] 先回答三个问题，帮你配一个合拍的。            （按钮：开始）
[3] Q1 怎么称呼你？                               （输入框；占位「昵称或真名都行」；可跳过→「匿名搭子」）
[4] Q2 你平时是——                                 （三选：在上学 / 在上班 / 都有一点·或者都没有）
[5] Q3 你一般什么时候坐下来干活？                 （四选：早上 / 下午 / 晚上 / 深夜；多选允许）
[6] 正在为你匹配搭子……                           （3 秒，进度点点点）
[7] 已匹配 · Yua（也是第一次使用）
    匹配理由：都是一个人学不进去的那种。            （停 2 秒）
[8] → 开局翻车（已定稿，她在打游戏被抓包）
```
- Q1 的答案就是 `player_nickname`，**Ep0 的取名反应改为读这个**（她「看到系统资料上你的名字」而不是问你）。
  取名反应台词微调 🅳：「资料上写你叫{name}——哦？这是本名？」／「{name}……这是网名吧，哪部作品的？」／整活名照旧。
  跳过时她说：「资料上是『匿名搭子』。行，很有安全感。那我先叫你搭子。」（之后 Ep1 她再问一次，可再跳过）
- Q2 → `player_role ∈ {student, worker, mixed}`：Ep14 / Ep28 / Ep45 的学生版·上班版；AI 上下文包一行 `player_role=`；
  期末季 / 高考日的问候只发给学生；「周一」「周五」的问候只发给上班。
- Q3 → `player_usual_slots`：问候只在「非惯常时段」出现才惊讶（「你这个点来？稀客」），惯常时段说「准时」。
- **回访玩家不再看到问卷**。设置里可以改称呼（她会反应：「改名了？行，我记一下。以前那个我不会忘的。」）
- 匹配理由是固定一句；玩家答什么都一样——因为她的理由本来就只有这一个。

## B · 开场问候 · 分层选择器

玩家打开游戏、点她第一下，她说的第一句话按**优先级**取，取到就停，不叠加：

| 优先 | 条件 | 说什么 | 池大小 |
|---|---|---|---|
| 1 | 特殊日期（春节、中秋、跨年、高考、期末季、台风季…） | 日期专属一句 + 正常问候 | 每个 2 句 |
| 2 | ≥ 7 天没来 | 长时未见（她交代自己这几天，不问你去哪了） | 4 |
| 3 | 3–6 天没来 | 几天没见 | 4 |
| 4 | 「上次你说」回访条件满足（≥3 天、有存档、AI 开着） | 用你上次打的字开场（AI 一句）→ 脚本兜底一句 | AI |
| 5 | 本子有新变化（现实日期过了一天以上） | 顺口提一条本子变化（见 D） | 每条目 2 句 |
| 6 | 同一天回来（≤30 分钟 / 当天第 N 次） | 短回流 | 3 + 3 |
| 7 | 时段 × 当前章 | 常规问候 | 5 章 × 4 时段 × 2 = 40 |

### B1 · 常规问候（时段 × 章）🅳
每句两拍：第一拍是她此刻在干嘛（和本章工作有关），第二拍松劲。

**第一章 · 书店**
- 早：「早。店九点才开，我八点就坐这儿了。……不是勤快，是房间太冷。」／「早。荐书卡写到第二张，第一张撕了。」
- 午：「中午了。店里这个点只有一个客人，还是来吹空调的。」／「刚吃完，最不想动的点。你来了，那开吧。」
- 晚：「晚上好。刚下班，鞋都还没换。」／「傍晚这个光我挺喜欢的。适合什么都不干，可惜不行。」
- 夜：「这个点还醒着的，我大概跟你是一路人。」／「夜里挺安静的。店长睡了，海还醒着。」

**第二章 · 水族馆**
- 早：「早。今天周末班，六点就得去开灯，鱼比人起得早。」／「早。头发还是湿的，别问。」
- 午：「中午。投喂表演刚完，我又湿了一次。」／「午休。Hina 让我别在休息室写东西，我在休息室写东西。」
- 晚：「晚上好。刚从馆里回来，身上还有鱼的味道。我自己闻不到了，这才是最可怕的。」／「傍晚。小七今天没泼我。我怀疑它在憋大的。」
- 夜：「夜里的水族馆我值过一次班。全黑，只有水在动。……写到小说里了。」／「这个点还醒着。鱼也不睡，我查过。」

**第三章 · 咖啡店**
- 早：「早。早班六点半，我拉花拉出一只很生气的东西，老板说有辨识度。」／「早。今天第一杯是我自己的。」
- 午：「中午最忙那阵刚过。我的手在抖，不是咖啡，是被人催的。」／「午休十五分钟，我用十分钟写了一句。」
- 晚：「晚上好。打烊了，吧台是我的了。」／「傍晚客人少，我给每一杯失败的拉花打了分。最高三分。」
- 夜：「夜里的咖啡店没咖啡味，只有洗洁精味。奇怪。」／「这个点还醒着的，八成是今天第四杯的锅。」

**第四章 · 花店 · 天文馆 · 民宿**（按当前小节切换，各 4 句，先写花店）
- 早：「早。花店的早上要先给花换水，比给人做早饭还讲究。」／「早。今天要写四十张卡，手已经在抖了。」
- 午：「中午。刚替一个人写完给前任的卡，写得比我自己的小说顺。……不想聊这个。」
- 晚：「晚上好。花店打烊，剩下的花老板让我带了一枝。放在你看不到的那边。」
- 夜：「这个点还醒着。今天替四十个人说了话，轮到我自己反而没话。……有的，我写。」

**第五章 · 回书店**
- 早：「早。回来第一天，自动门居然开了。我站门口愣了三秒。」／「早。冬天的店，四张桌子空三张。刚好写东西。」
- 午：「中午。店长在睡觉，我在看他改的那个字。」／「中午了。没客人。我给自己冲了杯咖啡，像了一次企鹅。」
- 晚：「晚上好。稿子在店长桌上，我在这儿假装不在乎。」／「傍晚。明信片今天卖了两张。数了三遍。」
- 夜：「这个点还醒着。等回信的人是不会睡的，我查过，是真的。」／「夜里。第二本开了个头。别问，写完再说。」

### B2 · 回流（同一天）🅳
- ≤30 分钟：「诶，回来了。水还没凉。」／「回来了。我这句还没写完。」／「这么快。我以为你去泡面了。」
- 当天第 2 次：「又来了。今天第二次，我记着。」／「又是你。我这边刚坐下第二轮。」
- 当天第 3+ 次：「今天第三次了，你是不是不用睡觉。」／「行，今天我们都是不要命的那种。」

### B3 · 几天没见 🅳（她先交代自己，不问对方去哪了）
- 3–6 天：「诶，好几天没见。我这边……荐书卡写了三张，小说动了零行。」／「几天没见。我以为这 app 把你删了。」
  ／「你不在的这几天，我的自动门还是不开。汇报完毕。」／「回来了。我刚好也回来，昨天在馆里加了两天班。」
- ≥7 天：「一周了吧。我数了，不是在等，是顺便。」／「好久。我这边过了一整个梅雨季，你那边呢——不用答。」
  ／「你回来了。我先说我的：本子上划掉三条，加了两条，小说没动。扯平。」／「一周没见，我没换工作。……好吧换了，第三章的事。」
- ≥30 天：「……一个月。我以为你把 app 卸了。我没把你卸。」／「好久不见。我这边换了两份工，写了一章半。你不用汇报，我先说完了。」

### B4 · 「上次你说」AI 回访（优先 4）
- 条件：`player_said_*` 里有 ≥3 天前的一条（Ep5 你的事 / Ep26 早饭 / Ep30 天气 / Ep33 靠什么撑 / 任何 AI 分支的打字）。
- AI 指令要点：用那句话开场，一到两句，**不问进展、不给建议**，说完就放手；口吻是「我记得」，不是「我在等你汇报」。
- 脚本兜底（AI 关着）🅳：「对了，你上次说的那个——我没忘。就这句，不追问。」／「上次你说{key}。我记着呢，先说这个。」
- 频率上限：每 3 天最多一次；同一条记忆只回访一次。

## D · Yua 的小本子 v2（章回版）

### 一句话
她的本子是**玩家看得见的她的生活**：顶上一行永远是她的正事（会随剧情改名），下面 2–3 条日常（按当前章换池），
还有一两条**长线目标**（「攒一台不会黑屏的电脑」）。现实时间过一天以上再回来，条目会被划掉 / 拖延 / 新增，她顺口提一条。

### 本子结构
```
┌──────────────────────────────┐
│ 写一章                        │ ← 顶行：她的正事（见「顶行演变」）
│ 攒一台不会黑屏的 ▮▮▮▯▯        │ ← 长线目标（Ep20 起；进度按她真实打工天数走；Ep49 划掉）
│ 荐书卡三张 ✓                  │ ← 日常（本章池）
│ 回妈妈消息 …                  │ ← 拖延标记
│ 别打游戏                      │ ← 常驻梗，划掉又写上
│ 不催{name}                    │ ← 常驻梗（Ep5 之后出现）：她提醒自己不问你进展
└──────────────────────────────┘
```

### 顶行演变（随主线）
| 阶段 | 顶行 |
|---|---|
| Ep0–Ep1 | 我的小项目 |
| Ep2 直说后 | 写一章 |
| Ep12 第一章给你看后 | 改第一章 → 写第二章 |
| Ep24 后 | 第三章 |
| Ep39 结局选了后 | 结局（A/B 按你选的写：「回镇上」/「上飞空艇」） |
| Ep47 写完 | （划掉，空一行；Ep48 起写「给店长？」） |
| Ep53 给了店长 | 等 |
| Ep56 投了 | 等（第二个） |
| Ep57 退稿 | 不决定 → 划掉 |
| Ep60 后 | 第二本 |

### 日常池（按章）
- **书店**：荐书卡三张 / 补进货单 / 擦咖啡机 / 新书上架 / 给三年没人碰的那本擦灰 / 跟自动门谈判
- **水族馆**：周六早班 / 洗小七的杯子 / 背企鹅讲解词（已经会了） / 给 Hina 带早饭 / 晾工作服
- **咖啡店**：练拉花（像企鹅） / 写菜单牌 / 记老板的止痛药时间 / 第四杯之前停
- **花店 · 天文馆 · 民宿**：写四十张卡 / 给花换水 / 背流星雨时刻 / 民宿留言本抄一句 / 换床单
- **回书店**：明信片补货 / 数明信片 / 装作不在乎 / 改开头 / 投第二家
- **生活（全章）**：收衣服 / 买洗衣液 / 回妈妈消息 / 给绿萝浇水 / 修台灯 / 洗杯子（一周了） / 别打游戏 / 不催{name}
- **长线**：攒一台不会黑屏的电脑（Ep20–Ep49）／ 房租（每月一日出现，划掉时她说「这个月活下来了」）

### 回访掷骰（现实日期过了 ≥1 天）
1. 对 1–2 条日常掷：完成（细线划掉）40% / 拖延（加「…」）40% / 新增一条 20%。
2. 「别打游戏」每次 50% 被划掉再写上。
3. 顶行 25% 概率划掉重写（她又开了文档又关了）——Ep47 后不再。
4. 长线目标按**她的打工天数**推进（不是玩家的），到 Ep49 自动划掉。
5. 然后她**只提一条**变化（脚本池，AI 不参与）。同一天内本子不变、不重复提。

### 提变化的台词 🅳（每条目 2 句：完成 / 拖延）
- 荐书卡三张：「对了，卡写完了，三张。第三张我自己看了两遍。」／「卡……别看我本子。我知道。」
- 补进货单：「进货单交了。店长说『哦』。就一个字，我等了三天。」／「进货单还没写。它在本子上瞪我。」
- 收衣服：「衣服终于收了。给自己记一功，你不用鼓掌。」／「衣服还在外面。梅雨季，不怪我。」
- 回妈妈消息：「回了我妈。用的是你改的那句，她没吵。」／「我妈的消息……还没回。本子上那个『…』是我加的。」
- 别打游戏：「『别打游戏』又划掉了。是划掉『别』字。……当我没说。」／「今天没打游戏。本子上那行我留着，怕自己忘。」
- 洗小七的杯子：「小七的杯子洗了。仇人的脸擦得锃亮，我是不是有病。」／「杯子还没洗。它上面的脸在笑，我不想碰。」
- 练拉花：「拉花今天像了一次企鹅。老板说像鸭子。算像。」／「拉花……今天像一滩。不写了。」
- 写四十张卡：「四十张写完了。手是我的，字不像我的。」／「写到二十七张。剩下的明天，它们不会跑。」
- 数明信片：「明信片今天卖了两张。数了三遍，还是两张。」／「今天没人买明信片。我数了，零。」
- 攒电脑（进度条推进）：「电脑的钱又攒了一格。这周在馆里多站了两天。」／（Ep49 划掉）「买了。不会黑屏的那种。……希望。」
- 房租（每月一日划掉）：「房租交了。这个月活下来了。」
- 不催{name}：「本子上那条『不催{name}』——我做到了。」（**永远不会有「拖延」版**）
- 顶行划掉重写：「小说嘛……今天开了又关了。别问。」／「顶上那行我又写了一遍。不是拖，是……好吧是拖。」

### UI
- 任务面板加一页「她的本子」：手写体、细线划掉、拖延的「…」用铅笔灰；长线目标是五格小方块。
- 玩家侧本子和她的本子并排，**不比较、不排名**。
- 点她的本子任一条：她说该条目的一句话（同池），不展开。

### 引擎（≈200 行）
- 存档：`yua_notebook: {top: str, items: [{key, text, added_day, done_day|null, stalled: bool}], long: [{key, progress, total}], last_roll_day}`。
- `notebook_manager.gd`：按 `current_chapter` 取池；`roll_for_today()`；`pick_mention()` → 交给问候选择器（优先 5）。
- 数据：`data/dialogue/notebook_pools.json`（池 + 每条目的两句）。
- 对称缺席接口：她的「缺席日」（Ep32 的规则）也写进本子（「馆里加班 ×2」），玩家回来看得到。

## 工作量与顺序

| 块 | 工作量 | 顺序 |
|---|---|---|
| A 启动问卷（场景 + 存档 + 取名反应改读资料） | 半天 | 1 |
| B 问候选择器 + 池（40 常规 + 回流 + 几天没见 + 15 特殊日期） | 1 天（含写线） | 2 |
