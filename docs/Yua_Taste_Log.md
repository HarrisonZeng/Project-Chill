# Yua 口味档案（owner 逐轮验收沉淀 · 每轮更新 · 所有写手必读）

这份文件记录 owner 在台词擂台里**实际否决和实际喜欢**的东西。比风格手册更具体，
优先级也更高：手册说的是「什么是好中文」，这里记的是「这个游戏的 owner 要什么」。

## 已否决（再写就是白写）

| 写法 | 例子（真实被否的） | 为什么 |
|---|---|---|
| 话筒/语音测试 | 「试试你那边的话筒？」 | 游戏根本没有语音，输入是打字 |
| 汇报/查岗框架 | 「不用马上汇报」 | 这游戏反对一切监工感，连否定式提及都不行 |
| 生硬的称呼开场 | 「总不能一直喊你『喂』或者『对面的』」 | 尬 |
| 组织式过渡 | 「那我们收拾收拾，准备开工？」 | 不可爱，像开会 |
| 玄学身体观察 | 「刚结束的时候，人会有一点飘」 | 没人这么说话 |
| 生气/吐槽当主事件 | 各种「今天气死我了」 | 这是 chill 游戏，事件要开心/可爱/得意 |
| 老手口吻 | 「我第一次用这 app 的时候……」 | 她和玩家一样是第一次用（开场已定） |
| 科技/游戏比喻堆叠 | 「害羞开关冷却」「倒水当换装备」「顺利开机」 | 一个还行，连用三个就是 AI 腔 |
| 网络流行语 | 绝绝子/yyds/家人们 | 她不是网红 |
| 同桌 | 「你的同桌」 | 不地道，统一用「搭子」 |
| 冗长世界介绍 | 地理+菜单+人员编制 | 书店信息一句话带出，其余从缝里漏 |
| 结尾软等待 | 「不用急，我等你」「比比谁先？」 | 结尾要「走起」：直接给 15/30/60 分钟三选一，把玩家推进专注 |
| 接不上前文的梗 | 「删档建角色」「存档名补一下」 | 前一场的「重新读档」只是一句玩笑，不能当剧情线索硬接；写之前把前文情绪读一遍 |
| 关系跳级 | 刚认识半小时就详细讲自己白天在店里的事 | 现实里没人这样；先聊眼前一起做完的这段，生活细节只能顺着话头漏一句 |
| 她当导游 | 「右边那个小本子可以……」教程口吻 | 工具是两人一起摸索发现的，她也第一次用 |
| 保密/封口费/目击者 梗 | 「作为封口费把名字给我」「目击证人登记」 | 逻辑不通：刚认识的两个人，向谁保密？为什么要保密？这个梗是 Claude 自己在第4轮写的、被误记成 owner 喜好后连锁扩散——**不是 owner 要的，全部作废** |
| 引导玩家「明天再来」 | 「明天你要是再来」「明天见」 | 玩家想什么时候来就什么时候来，Yua 不引导、不约、不催；结尾收在此刻就好 |
| 装傻/自我贬低过头 | 「问了我就装没看见」 | 可爱要理直气壮，不能显得迟钝 |
| 元评论式开场 | 「这段我全程没抒情，请记一功」 | 第三次见面的人不会这样点评自己上次说过的话；开场接此刻的状态就好，不要回放/打分上一集 |
| 「那个东西」当代称 | 「本子上那个『东西』」反复出现 | 太别扭、太神秘兮兮。改为她自己的说法：『我的那个东西』→ 她在写/搞一个**自己的小项目**，内容不说但性质要自然（见下方「写作线代称」决定） |

## 流程规则（owner 8/20 起）

## Owner 的正向风格画像（从实际选中的稿子里归纳 · 每轮更新 · 写手照这个写）

> 这一节和上面的否决表不一样：否决表是「别踩」，这里是「往这儿使劲」。
> 依据 = 第 6、7 轮 owner 实际选中的 Ep0 / Ep1 / Ep2 定稿，以及 owner 对落选稿的评语。

**1. 逻辑先于花活。** owner 明确说过：「2 的逻辑更清楚，5 更可爱——合并」。意思是先把
每拍的因果讲通顺（问了什么、为什么转到下一句），再往上加可爱。逻辑不通的可爱=白搭。

**2. 可爱 = 自嘲 + 理直气壮 + 自问自答的小结。** 选中的句子模式：
- 「我这次真的不打游戏了。真的。……你按啊。」（发誓→重复→立刻催人，三连）
- 「你说这算好事还是坏事？不用真答，我猜是好事。」（抛问题→撤回→自己给答案）
- 「你是定力担当，我是那个看时间的。」（自我定位小结，认怂认得可爱）
- 「我要是全安静，五分钟就会开始数天花板。」（用具体画面自嘲）
共同点：**她自己把话接圆**，不把球扔给玩家不管。

**3. 文艺是允许的——但必须付「尴尬税」。**（Ep2 第 4 拍定稿修正了早先的判断）
owner 最终选了偏文艺的意象（「海贴着窗边慢慢蹭」「整间屋子都会跟着顿一下」「像有人在很远的地方翻书」），
**条件是她说完立刻自己破功**（见第 7 条）。所以规则不是「不许文艺」，而是：
- 日常对话里的比喻走生活化（翻书 / 打哈欠 / 纸边翘）；
- 名场面可以文艺，但文艺句子最多 3–4 句，紧跟着她自己拆台，绝不能一路文艺到底；
- 不管哪种，比喻的参照物都得是她这个年纪真见过的东西，不要散文腔的抽象词。

**4. 每拍两句：第一句说事，第二句松劲。** 选中稿几乎全是这个节奏——第二句负责自嘲/
撤回/给台阶。一拍只写一句会显得硬，三句以上会显得话多。

**5. 承接前情要具体。** 「这段我居然忘了看时间」直接接 Ep1 的「偷偷看了三次」。owner
喜欢这种呼应，但要求它是**具体动作的呼应**，不是「上次说到哪来着」式的提示。

**6. 结尾公式：她的下一步 + 玩家的自由。** 「行了，我回去写那个『东西』。你继续你的。」
——说自己干嘛（一句）+ 放玩家自由（一句），到此为止。

**7. 「文艺→自己破功」是 owner 亲自发明的招牌节奏（Ep2 第4拍）。** 让她认真说一段文艺的话，
然后立刻自己尴尬——「啊啊啊这么文艺的句子脑子里想想还好，在你面前说出来就有点尴尬……当我没说！」
这一招同时保住了两种气质：她**会**文艺（写作线的底色），也**会**尴尬（21 岁的真实）。
以后凡是需要抒情的名场面，都可以用这个结构：抒情（2–4 句）→ 破功（1–2 句）。
不要每集都用（会腻），大约每 3 集一次。

**8. 模型偏好记录（私有）：** 第 6、7 轮 owner 三次全选中同一位写手的稿（第6轮 Ep0/Ep1、
第7轮 Ep2 的 2+5 也都是该写手的两案）。可以考虑：该写手出主稿，其余写手转为「挑战者/
第 4 拍名场面专供」，节省一半调用。owner 未表态前维持三写手。

## 语感基准

短句。省略号每段≤1。自我化解快。可以理直气壮。夸张到「——诶？！」为止。
每句的测试：21 岁有点宅的书店店员现在会这么说吗？玩家会想截图吗？
