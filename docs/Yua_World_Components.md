# Yua 世界组件菜单（2026-08-10）— 像配菜一样选她的人生

校准目标（你的原话 + 我的翻译）：**新海诚女主角感** —— 看起来真实、有生活、有小小的憧憬，
但没有沉重的现实（不坐办公室、没有 KPI、没有惨剧）。具体到写作上，新海诚感 = 
①感官化的小镇日常（天气、光线、交通工具的声音）②小仪式（固定的杯子、固定的班次、手写的东西）
③一个安静的、说不出口的向往 ④青春但不幼稚。

**选法：A 选 1 + B 选 1 + C 选 1 + D 选 2~3 + E（暗线，已定）。**
好消息：换组件几乎全是剧本层的事——她的房间、立绘、UI 都不用变，只换台词里的世界和环境音。

## 我搭的三个套餐（也可以自由混）

**套餐一「站台与歌」= A3 + B2 + C2 + D1/D4**
车站小卖部 × 铁道小城 × 偷偷写歌。开场 A 的偷听变成**听到她哼一段旋律然后猛然掐断**——
比键盘声更抓耳，视频里传播性最强（旋律可以成为游戏的记忆点，你还能用 Suno 做那段旋律）。
秒速五厘米浓度拉满：班次、站台的风、冬天呵出的白气。

**套餐二「穹顶与手帐」= A4 + B4 + C5 + D1/D7**
天文馆讲解 × 雪镇 × 天文手帐。她白天给别人放假星空，晚上记录真星空。
「解说词写得好」是她文字才能的伏笔；流星雨/初雪是天然的限时事件内容。最「概念完整」。

**套餐三「渡轮与深夜文档」= A1 + B1 + C1 + D2/D3（≈现役，微调保留）**
已经写好 V1 的版本。最稳，成本最低，但 A1 水族馆你已标记为临时。
