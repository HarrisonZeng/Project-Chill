## 2. 玩家为什么爱它（情感内核——要保住/学到手的东西）

这些是最高赞评价反复描述的「魔法」，和 `AGENTS.md` 的北极星几乎逐条对上：

- **零压力共处**：`不催你闯关、不逼你变强`、`待在那里你不会有任何压力`、
  `像小动物/猫猫一样，自己干自己的，偶尔说两句，不干扰你`（rellit 156赞、卖掉闲置 高赞）。
  → 这正是我们「co-presence-first、Yua 忙自己的」要复刻的手感。
- **被打扰会「嫌弃」**：`专注期间一直打扰她还会被她嫌弃`（路过一般玩家 640赞）。
  → 我们已有（连点后的「……」反应）——**被市场验证是加分项**，可以做得更有戏。
- **她会偷看你、会脸红、会提醒你专心**：`聪音连忙把脸朝回屏幕，小脸红扑扑的`、
  `点击她还会提醒我专心学习`（YY_MK 244赞）。→ 轻互动的甜点，低成本高回报。
- **靠番茄钟升级→更多互动→成就感与回访动机**：玩家83463663 明确说这是他持续用下去的原因。
  → **正是我们的模型**（专注推进故事）——继续坚持，别被「轻点也能解锁」诱惑。
- **她有自己的人生/烦恼，才让人上头**：AlbertFraser（1233 小时！）整段描述她
  `接通话前换衣服`、`说早上好`、`离座去拿饼干`、`看窗外`、`创作被打扰会抱怨/沉默`、
  `爷爷的收音机`、`出版《夏日暴走》后同学眼光变了`、`灵感不足会头痛`。
  → **这就是我们剧集式小披露要达到的纵深**；Yua 的「写作回避线」是我们独有的同类深度。
- **共鸣式背景**让玩家觉得「志同道合」：多条考研/艺考/大四迷茫的长评把游戏当情绪出口。
  → 我们的受众画像清晰：**学生 + 备考 + 独处 + 缺一个安静的陪伴**。宣传文案可直接对这群人说话。
- **可截图的句子＝传播力**：`兄弟你不是喜欢短发眼镜娘，你只是少一个陪伴的人`、
  `世界被调成了静音模式`——这类金句就是 小红书/B站 的自来水。
  → 直接喂给写作 arena 的「值得截图吗」标准（见 `Yua_Taste_Log.md` / `Chinese_Style_Guide.md`）。

## 3. 差评与「方向担忧」——我们要主动避开的坑

- **解锁太肝、和在线时长挂钩**：装饰「挂好几小时解锁一个，甚至上千小时的徽章，物价不合理」
  （YY_MK 244赞加更）；另有玩家专门发帖教「改金币」，并劝`别为了给她买东西一直学习，自己也要休息`。
  → **红线警示**：绝不能把温暖/外观锁进惩罚性的在线时长肝度。我们「专注推进故事、但绝不做成打卡交易」的
  设计正好避开——这是可宣传的差异点。
- **「保持纯粹、别膨胀」**：多位重度玩家（芥莨子、玩家83463663、木木枭）担心番茄钟赛道
  `越来越卷美少女`，希望`保持纯粹、别臃肿`，`待办/日历从没用过`。
  → 支撑我们的极简主义；**别往重生产力工具堆功能**。
- **对制作组方向的担忧（"桂南"/供在高阁）**：打工吧阿米娅等担心官方`打造完美女性伴侣却置于高阁`、
  没创意工坊。→ 提醒：Yua 要「可亲近的 peer」，不是「被供起来的完美偶像」。
- **共处何时失效**：问我问题我会希腊奶指出——**用电脑上网课/必须一直用电脑时，把她挂后台督促作用微乎其微**，
  更适合`在纸面上学习、偶尔查电脑`的场景（或双屏）。
  → 我们的「在线通话」定格框天然是「另一块屏/另一个窗口里的人」——文案要讲清**适用场景**，别过度承诺。
- **白噪音太重复不自然**：木木枭「下雨不像下雨，像一直开淋雨喷头」。
  → 若我们做环境音，注意做**有起伏的循环**，别一小段死循环。
- **纯乐器 vs 人声**：木木枭等明确偏好**无人声纯音乐**（有人声反而分心）。
  → 我们的 Suno BGM 方向对；语音（TTS）继续 defer 是对的，且要可关。

## 4. 相对 8/09 Steam 版新增的点（中国区特有信号）

1. **「她也休息」** 的诉求（Steam 版没突出）——对 Yua＝peer 是绝佳、独有的落点。
2. **在线时长肝度 + 内购**引发的明确反感与「改金币」教程——**反面教材**，坚定我们不做交易式解锁。
3. **方向担忧（桂南/供在高阁、别卷美少女）**——中国核心玩家对「完美女友化」是警惕的，

5. **适用场景的诚实边界**（纸面学习 vs 全程用电脑）——可写进宣传，避免差评。

## 5. 三条落到 roadmap 的结论（在 8/09 版基础上更新）

1. **概念视频卖点顺序不变，但加一条中国区钩子**：①她会记得你 → ②她听得懂你随便打的话
   （Type Mode / 取名反应）→ ③一起专注推进她的故事 → **④她也有自己的生活，会休息、会看窗外**
   （直接回应「希望她也休息」这条独有诉求，且强化 peer 感）。
2. **便宜且高契合的近期功能**（全部利用现有字段/语料池思路）：
   - 窗景/天色**接真实时间**（已有窗景列表 + 4 时段问候，接一下即可）；
   - **节日/季节问候语料池**（极便宜，直接进现有 pool 机制）；
   - Yua「**长时挂机 → 自己起身/看窗外/去拿点心**」的空闲小动作（peer 感，独有卖点）。
3. **明确不做的事（写进设计红线，也是宣传差异点）**：不做在线时长肝度解锁、不做交易式内购、
   不往重生产力工具膨胀、不把 Yua「完美偶像化」。这些正是 CWYL 差评区被顶起来的主题。
